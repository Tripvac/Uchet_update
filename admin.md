# Руководство администратора: Telegram-бот ПОБ «Учёт»

Все тексты, ссылки и картинки бота хранятся в базе данных PostgreSQL — их можно
менять **без разработчика**, обычными SQL-запросами. Программный код при этом не
трогается.

Бот кэширует данные, поэтому изменения появляются **в течение 5 минут** (или
сразу после перезапуска бота).

---

## С чего начать: где выполнять запросы

1. Откройте панель вашей базы (для Neon: neon.tech → ваш проект → **SQL Editor**).
2. Вставьте нужный запрос из этой инструкции, поправьте текст/ссылку под себя.
3. Нажмите **Run**. Успех — «UPDATE 1» или «INSERT 0 1». Если написано
   «UPDATE 0» — строка не найдена (см. раздел про `INSERT` ниже).
4. Через ~5 минут проверьте в боте: `/start` и дойдите до нужного экрана.

> **Важно про кавычки.** Если в тексте есть апострофы или кавычки (`'`, `«»`),
> обычные одинарные кавычки в SQL сломаются. Поэтому во всех примерах ниже текст
> обёрнут в `$$...$$` — внутри можно писать что угодно, ничего экранировать не надо.

## 1. Тексты экранов (таблица `bot_content`)

Текст привязан к экрану (`screen_id`) и языку (`lang`: `ru` или `kz`).

**Изменить существующий текст:**

    UPDATE bot_content
    SET body = $$<b>Членские взносы на 2026 год</b>

    Сумма: 12 975 тг. Оплатить можно через Kaspi QR ниже.$$,
        updated_at = CURRENT_TIMESTAMP
    WHERE screen_id = 'topic_payment' AND lang = 'ru';

**Если текста для экрана ещё нет** (бот показывает запасной текст из файлов, а
`UPDATE` пишет «UPDATE 0») — добавьте строку. Этот запрос и создаёт, и обновляет:

    INSERT INTO bot_content (screen_id, lang, body)
    VALUES ('info_edu', 'kz', $$<b>Оқу орталықтары</b>

    Мәтінді осында жазыңыз.$$)
    ON CONFLICT (screen_id, lang) DO UPDATE SET body = EXCLUDED.body;

### Форматирование текста

* Абзац — двойной перенос строки (просто нажмите Enter дважды внутри `$$...$$`).
* Жирный — `<b>...</b>`, курсив — `<i>...</i>`, ссылка — `<a href="https://...">текст</a>`.
* Обычные символы `<`, `>`, `&` можно писать спокойно — бот их не сломает
  (например, «взнос < 30 000 тг» отобразится как есть).

## 2. Ссылки кнопок и каналов (таблица `bot_links`)

Ссылки меняются по ключу (`key`):

    UPDATE bot_links
    SET url = 'https://wa.me/77771234567',
        updated_at = CURRENT_TIMESTAMP
    WHERE key = 'whatsapp_manager';

Доступные ключи:

| Ключ | Куда ведёт |
| --- | --- |
| `channel_news` | Официальный Telegram-канал (для подписки) |
| `chat_accountants` | Общий чат бухгалтеров (для подписки) |
| `social_youtube` / `social_tiktok` / `social_inst` / `social_site` | Соцсети и сайт |
| `join_form` | Форма вступления «Вступить в ПОБ» |
| `whatsapp_manager` | Контакт менеджера в WhatsApp |
| `outsource_form` | Заявка на услуги аутсорсинга |
| `login_check_form` | Проверка / реестр личного кабинета |
| `internal_docs` | Внутренние документы на сайте |
| `about_website` | Официальный сайт ПОБ |
| `cpe_hours` | Памятка (PDF) по часам повышения квалификации |

## 3. Картинки и QR-коды (таблица `bot_media`)

Бот берёт медиа в таком порядке: закэшированный `telegram_file_id` → `source_url`
(ссылка на файл на сайте) → локальный файл в проекте (аварийный запас). Поэтому
**заменить QR или памятку можно самому, без разработчика и деплоя** — одним SQL.

Ключи медиа:

| Ключ | Что это |
| --- | --- |
| `kaspi_qr` | Картинка Kaspi QR на экране оплаты |
| `cpe_hours_doc` | Памятка (PDF) по часам повышения квалификации |

**Как заменить QR-код или памятку:**

1. Загрузите новый файл на сайт (например, в `/upload/bot/`) и скопируйте его
   прямой URL.
2. Выполните (пример для QR):

        UPDATE bot_media
        SET source_url = 'https://pob.uchet.kz/upload/bot/kaspi_qr_2027.png',
            telegram_file_id = NULL,
            updated_at = NOW()
        WHERE key = 'kaspi_qr';

   Для памятки — то же самое, но `WHERE key = 'cpe_hours_doc'` и ссылка на PDF.

3. Обнуление `telegram_file_id` обязательно: оно сбрасывает старый кэш, иначе бот
   продолжит показывать прежний файл. При следующей отправке бот заберёт файл с
   `source_url` и закэширует новый `file_id` сам.
4. Проверьте через ~5 минут: `/start` → «Являюсь членом» → тема оплаты.

> Локальный файл `assets/kaspi_qr.png` остаётся аварийным запасом на случай, если
> БД и `source_url` недоступны. Менять его через репозиторий больше не требуется.

---

## Как проверить, что изменения применились

Подождите до 5 минут (кэш) → в боте нажмите `/start` → дойдите до изменённого
экрана. Если не видно — проверьте, что запрос вернул «UPDATE 1»/«INSERT 0 1» и что
совпали `screen_id`/`lang` (или `key`).
